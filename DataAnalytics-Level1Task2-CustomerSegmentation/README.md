# OIBSIP Task 2 - Customer Segmentation Analysis

## Project Overview

This project performs customer segmentation using RFM analysis and K-Means clustering to identify different groups of customers based on their purchasing behaviour.

## Analysis Performed

- Dataset inspection and data cleaning
- Descriptive statistics
- RFM analysis
- Data standardisation using StandardScaler
- Elbow Method for selecting the number of clusters
- K-Means clustering
- Cluster visualisation
- Customer segment profiling
- Customer count analysis
- Marketing recommendations

## Customer Segments

- Regular Customers
- At-Risk / Inactive Customers
- High-Value / Loyal Customers

## Tools Used

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab
