# OIBSIP Level 2 Task 1 - House Price Prediction

## Project Overview

This project focuses on predicting house prices using Linear Regression.

The Ames Housing dataset is used to analyse the relationship between house characteristics and their sale prices.

## Analysis Performed

- Dataset inspection and exploratory data analysis
- Missing value analysis and handling
- Feature selection
- One-Hot Encoding of categorical features
- Correlation analysis
- Train-test split
- Linear Regression
- Model evaluation using MSE, RMSE and R²
- Actual vs predicted price visualisation
- Residual analysis
- Coefficient analysis
- Ridge and Lasso Regression comparison

## Selected Features

- Overall Qual
- Gr Liv Area
- Garage Cars
- Total Bsmt SF
- Year Built
- Full Bath
- Bedroom AbvGr
- Neighborhood

## Models Used

- Linear Regression
- Ridge Regression
- Lasso Regression
